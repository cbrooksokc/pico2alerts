# Terms and Conditions: [Pico2Alerts] Personal Alerts

Last updated: September 18, 2026

## Program description
[Pico2Alerts] is a personal, single-user alert program. Text messages are sent only to the project owner's own mobile number when a monitored condition is triggered (for example, a sensor reading crossing a set threshold). No messages are sent to any other person.

## Opting in
The owner opts in by entering their own mobile number into the project's configuration and enabling alerts. The owner may also text START to the program number to confirm the subscription.

## Message frequency
Message frequency varies based on monitored conditions.

## Costs
Message and data rates may apply.

## Opting out
Reply STOP at any time to cancel. You will receive one confirmation message and no further messages after that. To resume, reply START.
